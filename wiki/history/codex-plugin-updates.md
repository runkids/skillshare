# Codex Plugin Update Transactions

Global Codex plugin updates now support managed sources and imports with
reviewable registered local/Git marketplaces. This resolves the missing native
update command through supported scoped marketplace upgrade and selected
reinstall operations. CLI and dashboard use the same plugin service.

Preview evidence covers source content, versions, native config bytes, cache
state, account paths and affected marketplace plugins. Transactions preserve
enablement and unrelated caches, validate native installed version, restore old
state on failures, and retain private backups when concurrent edits prevent safe
recovery. Managed snapshots preserve Codex installation/authentication policies.
Selected inline TOML plugin tables are blocked before mutation because Codex
rewrites them. Project Codex installation remains unsupported.

Native Codex CLI 0.159.3 was exercised in the Linux devcontainer with managed and
imported local/Git plugins, disabled installs, shared marketplaces, denied native
policies and an injected failure after Git refresh. Unit and generated byte
preservation/rejection tests cover stale evidence, config edits, sibling edits,
wrong versions, partial failures and cancellation. Later native background
refreshes and process-crash recovery are outside the command transaction.
